# Kitap Tarayıcı — Windows 64 bit

Bu dal, yerel e-kitap ekran tarayıcısının indirme paketini içerir.

1. KitapTarayici-Windows-x64.zip dosyasını indirin ve tamamen bir klasöre çıkarın.
2. Baslat.bat dosyasını açın. Python kurulumu gerekmez.
3. Sayfa alanını ve sonraki sayfa düğmesini seçip taramayı başlatın.
4. Esc taramayı durdurur; yakalanan sayfalar korunur.

PDF ve görüntülü Word doğrudan oluşturulur. Düzenlenebilir Word için Tesseract OCR ve Türkçe dil verisi gerekir.

Program dosyaları bilgisayarınızda kalır. ZIP içinde kaynak kod ve kullanım kılavuzu bulunur.

19 otomatik test geçti. Gerçek Windows ekran/tıklama işlemleri Linux geliştirme ortamında doğrulanamadı; önce 3–5 sayfalık deneme yapın.
